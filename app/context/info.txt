// jak zbudowac i zainstalowac PRODUKCYJNA wersje na telefonie
1. Podlacz telefon kablem USB i wlacz debugowanie USB.
2. Sprawdz czy system widzi urzadzenie:
  adb devices
3. Zbuduj produkcyjny APK:
  npm run build:apk:local
4. Zainstaluj APK na telefonie:
  npm run install:apk:local
5. Na telefonie uruchom aplikacje WDMobile (bez sufiksu .dev ani .demo).

- Pokaż podłączone urządzenia: adb devices
- Mirror telefonu: scrcpy

Najprostsza sciezka do produkcyjnej instalacji na telefonie:
  npm run build:apk:local
  npm run install:apk:local
