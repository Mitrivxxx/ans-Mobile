Dev (uruchomienie na urządzeniu/emulatorze)
adb reverse tcp:8081 tcp:8081
npx expo start
- Uruchom na Androidzie: npx expo run:android

Narzędzia
- Pokaż podłączone urządzenia: adb devices
- Mirror telefonu: scrcpy

Prebuild (native)
- npx expo prebuild
- npx expo run:android

Budowanie release (Android)
cd android
gradlew assembleRelease
------------
release install
adb install -r app\build\outputs\apk\release\app-release.apk

testy
